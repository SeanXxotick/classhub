# ClassHub

An Android app for tracking a class section's fund (ledger) and its deadlines, quizzes and exams (schedule).

Final Course Output (FCO) for Software Engineering, BSM CS 3A.

## Stack

- Kotlin + Jetpack Compose
- MVVM architecture
- Firebase Authentication and Cloud Firestore

## Repository layout

| Path | Contents |
|---|---|
| `design/` | Screen mockups (`mockup.html`) |
| `app/` | Android project (to be added) |
| `docs/` | Project documentation (to be added) |

## Working in the group

- Do not commit directly to `main`. Make a branch (for example `yourname/schedule-screen`), push it and open a pull request.
- Do not commit real student data or `google-services.json`. Both are listed in `.gitignore`.
- Use fake sample data when testing.
